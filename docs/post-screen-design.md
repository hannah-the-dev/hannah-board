# 게시글 화면 설계

## 범위

- 화면 경로: `/post/{id}`
- 화면 파일: `src/main/resources/static/post.html`
- 백엔드 변경: 없음

## 데이터 기준

`PostResponse`의 `id`, `title`, `content`, `hits`, `createdAt`를 사용한다.

## 표시 규칙

- 저장 직후에는 저장 처리에서 전달받은 DTO를 사용해 화면을 구성한다.
- 저장 직후 화면에서는 조회수 증가 목적의 조회 서비스를 호출하지 않는다.
- 일반 접근에서는 백엔드의 기존 조회 흐름과 연결될 수 있도록 동일한 화면 구조를 유지한다.
- 저장 완료 상태를 알리는 안내 문구를 제공한다.

## 레이아웃

- 제목과 작성일·조회수를 상단에 표시한다.
- 본문은 줄바꿈을 보존한다.
- 게시판 돌아가기 링크를 제공한다.
- 모바일에서는 본문이 화면 밖으로 넘치지 않게 한다.
