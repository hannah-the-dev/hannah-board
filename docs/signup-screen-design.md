# 회원가입 화면 설계

## 범위

- 화면 경로: `/signup`
- 화면 파일: `src/main/resources/static/signup.html`
- 백엔드 변경: 없음

## 데이터 기준

`UserRequest`의 `username`, `password` 필드만 사용한다. 비밀번호 정책은 초기 버전에 적용하지 않는다.

| 화면 필드 | 전송 이름 | 타입 | 필수 |
| --- | --- | --- | --- |
| 아이디 | `username` | text | 예 |
| 비밀번호 | `password` | password | 예 |

## 레이아웃 및 동작

- 로그인 화면과 동일한 공통 헤더·햄버거 메뉴를 사용한다.
- 아이디 입력, 중복 확인, 중복 확인 결과, 비밀번호 입력, 가입 버튼 순서로 구성한다.
- 아이디가 변경되면 중복 확인 상태와 가입 버튼을 초기화한다.
- 중복 확인 성공 전에는 가입 버튼을 비활성화한다.
- 중복 확인 API 호출 경로는 기존 요구사항의 `/check-username?username=...`을 사용한다.
- 가입 폼은 `POST /signup`으로 전송한다.
- 가입 성공 후 자동 로그인 및 내 정보 이동은 백엔드 연동 작업에서 처리한다.

## 접근성

- 중복 확인 결과는 `aria-live="polite"`로 제공한다.
- 아이디와 비밀번호 입력은 `required`로 설정한다.
- 버튼은 모바일에서도 최소 44px 높이를 유지한다.
