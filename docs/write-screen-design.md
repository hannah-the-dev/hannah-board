# 글쓰기 화면 설계

## 범위

- 화면 경로: `/post/write`
- 화면 파일: `src/main/resources/static/write.html`
- 백엔드 변경: 없음

## 데이터 기준

`Post`의 입력 가능한 필드 중 제목과 내용만 화면에 노출한다.

| 화면 필드 | 전송 이름 | 타입 | 필수 |
| --- | --- | --- | --- |
| 제목 | `title` | text | 예 |
| 내용 | `content` | textarea | 예 |

조회수 `hits`는 서버가 관리하므로 입력 필드로 제공하지 않는다.

## 레이아웃 및 동작

- `POST /post/save`로 폼을 전송한다.
- 모바일에서는 제목과 본문을 세로로 배치한다.
- 데스크톱에서는 최대 760px 카드로 중앙 정렬한다.
- 저장 버튼과 게시판 돌아가기 링크를 제공한다.
- 제목과 내용이 비어 있으면 브라우저 기본 검증으로 전송을 막는다.
