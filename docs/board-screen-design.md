# 게시판 화면 설계

## 범위

- 화면 경로: `/board/list`
- 화면 파일: `src/main/resources/static/board.html`
- 백엔드 변경: 없음

## 데이터 기준

목록은 `PostResponse`의 `id`, `title`, `hits`, `createdAt`를 사용한다. 본문은 목록에 표시하지 않는다.

## 레이아웃 및 동작

- 모바일에서는 게시글을 세로 카드 목록으로 표시한다.
- 데스크톱에서는 목록 폭을 넓혀 읽기 편하게 표시한다.
- 게시글 카드에는 번호, 제목, 조회수, 작성일을 표시한다.
- 게시글 선택 시 `/post/{id}`로 이동한다.
- `글쓰기` 버튼은 `/post/write`로 이동한다.
- 페이지네이션은 모바일에서 줄바꿈 없이 축약된 버튼으로 표시한다.
- 게시글이 없는 상태를 위한 빈 상태 구조를 둔다.
- 비로그인 사용자도 글쓰기 버튼을 볼 수 있다.
