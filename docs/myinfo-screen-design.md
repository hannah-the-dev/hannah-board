# 내 정보 화면 설계

## 범위

- 화면 경로: `/user/{id}`
- 화면 파일: `src/main/resources/static/myinfo.html`
- 백엔드 변경: 없음

## 데이터 기준

제공된 `UserResponse` 필드만 화면에 표시한다.

| 필드 | 표시 |
| --- | --- |
| `id` | 회원 번호 |
| `username` | 아이디 |
| `role` | 역할 |
| `status` | 상태 |
| `createdAt` | 가입일 |

비밀번호는 DTO에 포함되어 있지 않으며 화면에도 표시하지 않는다.

## 레이아웃

- 공통 헤더와 햄버거 메뉴를 사용한다.
- 로그인한 사용자의 아이디와 상태를 상단 요약 영역에 표시한다.
- 나머지 사용자 정보를 라벨·값 형태의 카드로 표시한다.
- 모바일에서는 1열, 데스크톱에서는 최대 640px 중앙 카드로 표시한다.
- 게시판으로 이동하는 보조 링크를 제공한다.

## 백엔드 연동 전 상태

정적 UI 검증을 위해 샘플 `UserResponse` 값을 사용한다. 실제 `/user/{id}` 경로의 Thymeleaf 모델 연결은 백엔드 작업 범위에서 처리한다.
