# 로그인 화면 설계

## 범위

- 화면 경로: `/login`
- 화면 파일: `src/main/resources/static/login.html`
- 다음 화면 작업 대상: 로그인 화면만
- 백엔드 변경: 없음

## 데이터 기준

로그인 폼은 제공된 `UserRequest`의 입력 필드에 맞춘다.

| 화면 필드 | 전송 이름 | 타입 | 필수 |
| --- | --- | --- | --- |
| 아이디 | `username` | text | 예 |
| 비밀번호 | `password` | password | 예 |

로그인 실패 메시지는 확정 정책을 기준으로 화면에 표시할 수 있는 영역만 제공한다.

- `ID가 올바르지 않습니다`
- `비밀번호가 올바르지 않습니다`
- `로그인에 실패했습니다`

## 레이아웃

- 공통 헤더에 홈 링크와 햄버거 메뉴를 배치한다.
- 콘텐츠는 모바일에서 화면 좌우 16px, 데스크톱에서 최대 440px로 제한한다.
- 폼은 아이디, 비밀번호, 로그인 버튼 순서로 구성한다.
- 회원가입 링크를 로그인 버튼 아래에 제공한다.
- 입력 요소와 버튼의 최소 높이는 44px로 한다.

## 상태 및 접근성

- 빈 입력은 브라우저 기본 `required` 검증을 사용한다.
- 비밀번호는 `autocomplete="current-password"`를 사용한다.
- 오류 영역은 `aria-live="polite"`로 선언한다.
- 햄버거 메뉴는 인덱스 화면과 동일하게 오버레이·`Esc` 닫기를 지원한다.

## 구현 제한

- 로그인 인증, 세션 생성, 사용자 조회는 이번 화면 작업에서 구현하지 않는다.
- 폼 action은 요구사항의 `/login`을 유지한다.
- 로그인 성공 후 이동은 백엔드 연동 작업에서 `/user/{id}`로 연결한다.
