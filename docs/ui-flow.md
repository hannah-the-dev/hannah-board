# Hannah Board UI 전체 플로우

## 작업 순서

규약에 따라 다음 순서로 한 화면씩 진행한다.

1. 인덱스 `/`
2. 로그인 `/login`
3. 회원가입 `/signup`
4. 내 정보 `/user/{id}`
5. 게시판 `/board/list`
6. 글쓰기 `/post/write`
7. 게시글 `/post/{id}`

각 화면은 `설계 문서 작성 → UI 구현 → 브라우저 테스트 및 스크린샷 검증 → 테스트 리포트 기록` 순서로 완료한다.

## 화면별 설계 요약

| 순서 | 화면 | 핵심 목적 | 주요 이동 |
| --- | --- | --- | --- |
| 1 | 인덱스 | 서비스 진입점과 주요 바로가기 제공 | `/login`, `/signup`, `/board/list` |
| 2 | 로그인 | 사용자 인증 및 내 정보 이동 | `/user/{id}` |
| 3 | 회원가입 | 계정 생성 및 자동 로그인 | `/user/{id}` |
| 4 | 내 정보 | 로그인 사용자 정보 표시 | `/`, `/board/list` |
| 5 | 게시판 | 게시글 목록·페이지 이동 | `/post/{id}`, `/post/write` |
| 6 | 글쓰기 | 제목·내용 입력 및 저장 | `POST /post/save` |
| 7 | 게시글 | 저장 결과 또는 일반 조회 표시 | `/board/list` |

## 공통 UI 설계

- 모바일 우선의 반응형 레이아웃을 사용한다.
- 모든 화면의 좌측에 햄버거 메뉴를 배치한다.
- 메뉴는 로그인 여부에 따라 `내 정보`, `로그인`, `회원가입` 노출을 바꾼다.
- 공통 스타일은 `src/main/resources/static/css/`에 두고 템플릿에서 공유한다.
- 인덱스는 별도 DTO가 없으므로 서버 값에 의존하지 않는 정적 콘텐츠로 구성한다.

## 첫 번째 화면 범위: 인덱스

이번 작업에서는 인덱스 화면만 구현한다.

- 신규 진입점: `/`
- 화면 파일: `src/main/resources/static/index.html`
- 필요한 백엔드 변경: 없음. 정적 리소스 기본 매핑으로 먼저 검증한다.
- 바로가기: 회원가입, 로그인, 게시판
- 공통 메뉴: 홈, 로그인, 회원가입, 게시판
- 제외 범위: 로그인 처리, 세션 연동, 다른 화면의 리디자인

> Thymeleaf 공통 레이아웃과 루트 컨트롤러 연결은 백엔드 변경 승인이 필요한 후속 작업으로 분리한다.
